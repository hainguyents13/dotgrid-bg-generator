Trình tạo background chấm vuông

Thả nhiều file vector vào, xếp lớp và chỉnh riêng từng hình, rồi xuất PNG, SVG hoặc lấy CSS.

Khổ ảnh

Khổ in thật

SVG mang sẵn đơn vị mm nên nhà in mở ra là đúng khổ, không phụ thuộc số pixel. Đây là lựa chọn nên dùng cho standee.

Nền và chấm

Các lớp hình

Kéo file SVG hoặc PNG vào đây, hoặc bấm để chọn

Lớp nằm trên trong danh sách sẽ đè lên lớp bên dưới. Bấm vào một lớp để chỉnh riêng nó.

Chỉnh lớp

Kéo thẳng hình trên khung xem trước để dời lớp đang chọn. Giữ Alt rồi lăn chuột để phóng to thu nhỏ, bấm đúp để đưa về giữa.

Vệt sáng dưới đáy

Xuất file

CSS lặp chỉ gồm nền và chấm đều, không kèm hình hay vệt sáng. Muốn giữ hình thì bạn xuất PNG hoặc SVG nhé.
